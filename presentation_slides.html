Input Specification and Scope Choices

Slide 2 / 7

📝 Sample Input

// Sample Arithmetic Expression
total = 12.5 + qty * 2;
flag = count >= 10;
invalid_test = 50 $ 4;

Key Requirements Handled:

  • Tracks 1-based line & column positions.
  • Skips single-line (//) & multi-line (/* */) comments.
  • Identifies unexpected characters ($) & continues scanning.

🎯 Scope Boundaries

✔ Within Scope (Lexical Level):

  • Identifiers, integers, decimals.
  • Arithmetic (+ - * / % ^) & assignment (=).
  • Relational comparisons (>= > <= < == !=).
  • Delimiters (( ) ; ,).

✖ Outside Scope:

  • Syntax checking (AST parsing).
  • Semantic arithmetic expression evaluation.

⚖️ Competing Case 1: >= vs >

• Conflict: In >=, both > and >= could match.

• Resolution: JFlex Longest Match (Maximal Munch) chooses 2 chars (>=) over 1 char (>). Emits OP_GTE.

⚖️ Competing Case 2: Decimal 12.5 vs Integer 12

• Conflict: Digits 12 match {Integer}.

• Resolution: {Decimal} matches 4 characters. Longest match takes precedence, emitting a single DECIMAL token.

🎨 DFA for DECIMAL Token

Pattern: (0 | [1-9][0-9]*)\.[0-9]+

      '0'
 (S0) ----> (S1) --'.'----\
   │                       \
   │ '1'-'9'       '.'      v       '0'-'9'        '0'-'9'
   +------> (S2) --------> (S3) -----------> ((S4)) <───+
             ^               │                  │       │
             \───'0'-'9'─────/                  \───────/

• S4 is the double-ring accepting state.

• Rejection occurs if no digits follow period (e.g. 12.).

Test Evidence and Bug Correction

Slide 5 / 7

🧪 Test Coverage (16 Cases - 100% PASS)

  • Normal (6) N01–N06: Arithmetic, precedence, power/mod, relations, multi-statement, comments.
  • Boundary (5) B01–B05: Empty input, contiguous operators (a>=b>c==d), decimal vs int, division vs comment, EOF literal.
  • Invalid (4) E01–E04: Dollar symbol ($), illegal # & @, double dot (3.14.15), tilde & quotes.
  • Bug Test (1) BUG01: Dangling dot decimal.

🐞 Bug Found and Correction

Initial Bug: Decimal pattern loosely used *:

Decimal = {Integer} \. {Digit}*  // BUG!

Allowed 12. (with 0 fractional digits) to be matched as a Decimal token.

Corrected Rule: Enforced at least one digit with +:

Decimal = {Integer} \. {Digit}+  // FIXED!

In 12. + 5, 12 matches INTEGER, . is reported as lexical error, and + 5 continues cleanly.
